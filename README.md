# 🐾 GoRaksha - Pashu Sanjeevini
A comprehensive web-based Veterinary Healthcare Management System built using **Python** and **Django**, specifically designed to empower rural farmers with instant access to animal healthcare, emergency guidance, and government schemes.

---

## 🌟 Key Features
- **Doctor Discovery:** Connects rural farmers with nearby veterinary doctors and hospitals instantly.
- **Emergency First-Aid Guides:** Provides actionable, step-by-step first-aid and emergency guidance for livestock accidents and illnesses.
- **Government Schemes Directory:** Offers up-to-date and vital information on animal husbandry government schemes to support informed decisions.
- **Farmer-Veterinarian Communication:** Built with a clean, responsive UI (Bootstrap 5) ensuring high accessibility across mobile and desktop devices for rural users.

---

## 📈 Real-World Impact & Field Validation
Unlike typical academic projects, GoRaksha has been rigorously validated on the ground:
- **100+ Villages Covered:** Conducted extensive field validation across more than 100 villages to understand and solve actual challenges faced by farmers.
- **Stakeholder Collaboration:** Engaged directly with farmers, local veterinary hospitals, and government veterinary department officials to collect feedback and refine the platform's core features.

---

## 🛠️ Tech Stack Used
- **Backend:** Python, Django Framework
- **Database:** SQLite / MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Development Tools:** Git, GitHub
